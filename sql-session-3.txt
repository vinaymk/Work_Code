---> Joins
     ---> Till now we saw how to select the data from a single table...
	 ---> The whole concept of relational DB means that if there is some relation between data then we should be 
	 able to use that and fetch or query the data accordingly...
	 
	 For doing that --> we use concept of joins-->
	 also I have explained the concept of promary key and foreign key.. which are essesntial to understand the joins...
	 
	So, The SQL JOIN statement is used to combine rows from two 
	tables based on a common column and selects records that have matching values in these columns. 
    
    SYntax:
	SELECT columns_from_both_tables
    FROM table1
    JOIN table2
    ON table1.column1 = table2.column2
    	
	Here,

    table1 and table2 are the two tables that are to be joined
    column1 is the column in table1 that is related to column2 in table2	
	
	
	SELECT Customers.customer_id, Customers.first_name, Orders.amount
		FROM Customers
		JOIN Orders
		ON Customers.customer_id = Orders.customer;

	LEFT Join:
	The SQL LEFT JOIN combines two tables based on a common column. It then selects records having matching values 
	in these columns and the remaining rows from the left table.
	
SELECT Customers.customer_id, Customers.first_name, Orders.item
FROM Customers
LEFT JOIN Orders
ON Customers.customer_id = Orders.customer_id;
	
similarly RIGHT

then Full outer join

Here, the SQL query performs a FULL OUTER JOIN on two tables, Customers and Orders. 
This means that the result set contains all the rows from both tables, including the ones that don't have common customer_id values.

SELECT Customers.customer_id, Customers.first_name, Orders.item
FROM Customers
FULL OUTER JOIN Orders
ON Customers.customer_id = Orders.customer_id;
